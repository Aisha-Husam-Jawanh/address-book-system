# Address Book System 📖

A Python-based command-line application for managing contact information. This project was developed as a course assignment for Fundamentals of Programming.

* **Dima Mohammed Balousha**

---

## 🌟 Features
* **Add New Contact:** Add a contact with name, type (Family, Personal, Work, Other), and phone number.
* **Duplicate Prevention:** Checks if the phone number is already registered before adding.
* **Search Contacts:** Search by name (partial search supported) or by unique phone number.
* **Delete Contacts:** Remove contacts by name or phone number.
* **Display All:** View all stored contacts in a clean format.
* **Data Validation:** Automatically assigns invalid types to `others`.
